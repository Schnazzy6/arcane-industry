# Сервер Arcane Industry 0.2.0 через Radmin VPN

Для 3–4 игроков. Java 21 включена в серверный архив; отдельно ставить её для сервера не нужно.
Серверу выделено **8 ГБ ОЗУ**. Для одновременной игры и хостинга желательно 24–32 ГБ общей памяти.
На машине хоста сейчас достаточно памяти, но производительность четырёх игроков ещё нужно проверить игрой.

## Первый запуск

1. Распакуй **ArcaneIndustry-0.2.0-Server.zip** в отдельную папку. На машине автора уже подготовлена папка `server` рядом с проектом.
2. Включи Radmin VPN. Создай свою закрытую сеть через **Сеть → Создать новую сеть** и передай друзьям имя и пароль лично.
   Инструкция Radmin: [официальная справка](https://www.radmin-vpn.com/help/).
3. Один раз запусти **Configure-Firewall.cmd** и подтверди запрос Windows.
   Правило разрешает TCP 25565 только на адаптере Radmin и только адресам сети `26.0.0.0/8`.
   Проброс портов на роутере не нужен. Не отключай брандмауэр целиком.
4. Запусти **Start-Server.cmd**. Дождись строки **Done**. Окно должно оставаться открытым.
5. Скрипт покажет адрес вида `26.x.x.x:25565`; передай его друзьям. Хост подключается по этому же адресу.
6. Все игроки импортируют клиентский архив того же релиза. На сервере по умолчанию новый мир **world**,
   обычная сложность, выживание, четыре места. Старые тестовые миры сюда не переносились.

Скрипт при каждом запуске сам определяет текущий IPv4 Radmin и привязывает сервер только к нему.
Если адаптер отсутствует или порт занят, запуск останавливается с объяснением. После смены IP повтори настройку брандмауэра.

## Каждый вечер

Включи Radmin → **Start-Server.cmd** → дождись Done → играйте.
Для завершения введи **stop** в консоли сервера и дождись сохранения мира и завершения процесса.
Не закрывай окно крестиком и не выключай ПК во время сохранения.

## Полезные команды консоли

Без начального `/`: `list` — игроки; `say текст` — объявление; `save-all flush` — сохранить;
`stop` — сохранить и завершить. `op Ник` выдаёт административные права; выдавай только себе.
`whitelist add Ник` добавляет игрока, `whitelist on` включает ограничение по списку.
По умолчанию белый список выключен, доступ ограничен Radmin и лицензионной авторизацией Minecraft.
Не публикуй пароль Radmin, ops.json и whitelist.json в GitHub.

## Авторизация

По умолчанию **online-mode=true**: нужны действующие Minecraft Java аккаунты, даже через Radmin.
VPN не заменяет авторизацию игры. Переключение режима меняет UUID игроков и может привести к
отдельным инвентарям/правам; не меняй его посреди игры без резервной копии.

## Резервная копия и обновление

1. Останови сервер командой `stop`.
2. Запусти **Backup-World.cmd**. Копия появится в `backups/world-ДАТА-ВРЕМЯ.zip`.
3. При обновлении распакуй новый сервер в новую папку. Перенеси только `world`, при необходимости
   `ops.json`, `whitelist.json` и свои изменения `server.properties`. Не смешивай старые и новые папки mods.
4. После запуска проверь инвентари и книгу квестов. Перед изменением рецептов всегда делай копию.

Для восстановления останови сервер, сохрани текущий `world` отдельно и распакуй нужную резервную копию в `world`.

## Где что находится

- `world` — мир, игроки и командный прогресс.
- `config/ftbquests/quests` — определения квестов; прогресс хранится отдельно в мире.
- `kubejs` — рецепты и правила сборки.
- `logs/latest.log` — диагностика; присылай при проблемах вместе с описанием действий.
- `user_jvm_args.txt` — память сервера: `-Xmx8G`. Менять только при остановленном сервере.

Если локальный запуск проходит, но друг не подключается: проверьте видимость друг друга в Radmin,
адрес/порт и правило брандмауэра. Проверка с другого компьютера нужна отдельно: её нельзя подтвердить одним локальным запуском.
