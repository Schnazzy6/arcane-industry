# Arcane Industry

Кооперативная экспертная сборка для 3–4 друзей: **Minecraft 1.21.1 · NeoForge 21.1.259 · Java 21**.
Технологии Modern Industrialization → Tech Reborn, магические школы, исследование и финал Avaritia.
Собственные рецепты, лестница снаряжения и **557 русских квестов с наградами**. Версия для друзей: **0.2.0**.

## Как установить и играть

1. Установи [Prism Launcher](https://prismlauncher.org/download/windows/).
2. Открой **Releases** справа на странице репозитория и скачай **ArcaneIndustry-0.2.0-Prism.zip**.
   Кнопка зелёная **Code → Download ZIP** скачивает исходники — это не готовая сборка.
3. В Prism: **Добавить сборку → Импорт → выбрать скачанный ZIP**. Не распаковывай архив вручную в папку Minecraft.
4. Войди в свой Microsoft-аккаунт с Minecraft Java. Prism загрузит игровые библиотеки.
5. Выбери Java **21**; обычно Prism находит или устанавливает её автоматически. Если нет — установи
   [Temurin 21](https://adoptium.net/temurin/releases/?version=21). Для игры выделено 8 ГБ памяти.
6. Установи [Radmin VPN](https://www.radmin-vpn.com/), нажми **Сеть → Присоединиться к существующей сети**.
   Имя и пароль сети получи у хоста лично; в репозитории их нет.
7. В Minecraft: **Сетевая игра → Добавить сервер**. Адрес: **Radmin-IP хоста:25565**, например `26.x.x.x:25565`.
   IP хоста виден рядом с его именем в Radmin; твой собственный IP вводить не нужно.
8. Все должны использовать один и тот же архив 0.2.0. Не обновляй моды по отдельности.

## Графика, текстуры и JEI

- Текстурпаки и оба набора шейдеров включены в архив вместе с настройками и текущим порядком текстур.
- По умолчанию: **Complementary Reimagined**, облегчённый профиль, 12 чанков, симуляция 6, лимит 120 FPS.
  Гарантии конкретного FPS нет — он зависит от ПК и места в мире.
- При низком FPS нажми **K**, чтобы выключить шейдеры, либо снизь прорисовку до 8 чанков.
  Более тяжёлый **Complementary Unbound + Euphoria** можно выбрать в меню видеонастроек → шейдеры.
- JEI: **R** — рецепт, **U** — применение, **A** — закладка (наведение на предмет).
  `@имя_мода` фильтрует по моду. Поле поиска по центру внизу; список имеет фон, закладки — слева.
  **Ctrl+O** скрывает/показывает JEI. Новая установка не содержит чужих поисков и закладок.
- **Configured** добавлен: меню модов → выбери мод → настройки. Доступность настроек зависит от самого мода.
  Серверные правила меняет хост, а не клиентский экран настроек.

## Квесты и команда

Книга FTB Quests доступна из инвентаря. В FTB Teams создайте одну команду и пригласите друзей:
прогресс будет общим, а награды каждый забирает лично. Предметы задания не отбирают.
В начале полезно читать основную ветку, параллельно изучая магию. Рецепты изменены — ориентируйся на JEI.
Книга ещё развивается: текущие 557 заданий не означают завершённое наполнение всего плана.

## Не подключается?

| Что видно | Что проверить |
|---|---|
| Connection refused / отказ | Хост запустил сервер и дождался `Done`; порт `25565`, IP именно хоста |
| Timeout / тайм-аут | Оба онлайн в одной сети Radmin; хост запустил настройку брандмауэра |
| Failed to verify username | В Prism войти в Microsoft-аккаунт с купленной Minecraft Java; сервер использует online-mode |
| Несовпадение модов | Импортировать тот же архив 0.2.0; не смешивать с предыдущей сборкой |
| Не хватает памяти | Выделить 8 ГБ при наличии хотя бы 16 ГБ ОЗУ, закрыть тяжёлые приложения |
| Проблемы с шейдерами | K отключает шейдер; перезапустить игру после смены пакета |

## Хосту

Скачай **ArcaneIndustry-0.2.0-Server.zip** из того же релиза. Полная инструкция — [SERVER-GUIDE.md](SERVER-GUIDE.md).
Сервер, клиент и мир — разные папки. Тестовые сохранения и аккаунты в архивы не включены.

## Авторы и исходники

Моды, текстурпаки и шейдеры принадлежат их авторам; названия и SHA-256 всех файлов находятся в
`release-manifest.json` и `FILES-SHA256.json` внутри клиента. Официальные страницы ключевых компонентов:
[Configured](https://github.com/MrCrayfish/Configured), [Complementary](https://www.complementary.dev/),
[Euphoria Patches](https://www.euphoriapatches.com/), [Fresh Animations](https://modrinth.com/resourcepack/fresh-animations).
В репозитории лежат настройки и исходники сборки; готовые архивы — в **Releases**.
